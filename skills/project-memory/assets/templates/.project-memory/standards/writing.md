# 写作约定

`dev-writing` 技能的项目取值和差异。通用规则见该技能，这里不重复。

## 目录

- [取值](#取值)
- [差异](#差异)

## 取值

| 项目 | 取值 |
| --- | --- |
| 文档语言 | 待补充 |
| 中英文之间加不加空格 | 待补充 |
| 面向用户的文档 | 待补充：如根目录 `README.md` |
| 面向开发者的文档 | 待补充：如 `docs/development.md` |
| 面向维护者的文档放在哪 | `.project-memory/`：需求、架构、接口、决定、计划、验收和测试状态 |
| 术语 | [项目术语表](../project/glossary.md) |

## 差异

| 规则 | 原因 | 适用范围 |
| --- | --- | --- |
| `docs/` 只放开发指南。设计、计划、工作包、验收记录和接口细节写进 `.project-memory/`；工具或技能生成的设计稿和计划不长期留在 `docs/`，结论并入记忆后删除 | `docs/` 里的内部文档不受记忆维护规则约束，容易和实现脱节 | `docs/` |
| 根 `README` 只写使用者看得到的效果，开发内容只放链接到面向开发者的文档 | 面向应用使用者，不混入内部开发说明 | 根目录 `README*` |
